# CLI Bridge Contract Examples v0

These examples accompany
[`docs/cli-bridge-contract/v0/`](../../../docs/cli-bridge-contract/v0/).

They are vendor-neutral reference artifacts. They use placeholder digests and
neutral IDs. They do not execute commands, contact models, mutate GitHub, rely
on RabbitMQ, or prove work completion.

Run:

```bash
npm run hacp:cli-bridge-examples
```

The check verifies that the expected example JSON files exist, parse as JSON,
and contain the public boundary fields used by this candidate package.
