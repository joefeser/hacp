# Historical HACP v0.3 Candidate Examples

These source-packet example paths are retained for backward-readable history.
Their placeholder digests were replaced by reproducible RFC 8785 JCS candidate
vectors when the executable conformance package was prepared.

The canonical validation corpus now lives in
[`schemas/v0.3-candidate/fixtures/`](../../../../schemas/v0.3-candidate/fixtures/).
That corpus and its manifest supersede these paths for conformance testing.

Everything remains candidate material. A computed digest proves integrity of
the declared bytes and domain; it does not authenticate an issuer, grant
authority, prove execution, or promote HACP v0.3 to a standard.
